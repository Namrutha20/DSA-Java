# Recursion

## Concepts Learned

- Base Condition
- Recursive Calls
- Call Stack
- Parameterized Recursion
- Functional Recursion
- Two Pointers + Recursion

## Problems Solved

1. Print Name N Times
2. Print 1 to N
3. Print N to 1
4. Sum of First N Numbers
5. Fibonacci Number
6. Reverse Array
7. Palindrome Check

## Key Learnings

- Every recursion needs a base condition
- Recursive calls solve smaller subproblems
- Space complexity comes from call stack
- Fibonacci introduces overlapping subproblems
