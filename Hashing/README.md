# Hashing

## Problems Solved

1. Valid Anagram
   - Pattern: Character Hashing
   - Time: O(n)
   - Space: O(1)

2. Majority Element
   - Pattern: Boyer Moore Voting Algorithm
   - Time: O(n)
   - Space: O(1)

3. Running Sum of 1D Array
   - Pattern: Prefix Sum
   - Time: O(n)
   - Space: O(n)

4. Subarray Sum Equals K
   - Pattern: Prefix Sum + HashMap
   - Time: O(n)
   - Space: O(n)
